# 테스트 보고서

## 범위

- 단위: Day.js 상대 시간 경계, BookmarkStore, LikeStore, 소유권 판정, ModalManager, JWT 단일 실행·정확한 9분 선제 갱신·코드 기반 실패 처리
- 통합: 피드 LNB/좋아요/북마크/작성 진입, 인증 폼 구조, POST 재시도 보존
- UI: 피드 수치·생성/편집 액션, 전체 딤드, 인증 50/50, 북마크·좋아요 페이지 공유, 상세/댓글 소유권 옵션, 설정 사용자 정보·Title3 중앙 제목, 여러 탭 접근 토큰 선제 갱신

## 환경과 수치

- Chromium, 1920×1080
- 콘텐츠 폭 480px, 중심 X 960px, LNB 폭 180px, 간격 40px: Playwright 허용 오차 내 통과
- 콘솔 오류와 로컬 에셋 404: 테스트 경로에서 발견되지 않음
- 목록 렌더링은 단일 요청/단일 프래그먼트 교체, 좋아요·북마크·댓글 변경은 대상 DOM만 갱신
- 동시 만료 2건에서 갱신 네트워크 호출 1회, 각 원 요청 1회 재시도
- 발급 후 8분 59초에는 갱신하지 않고, 정확히 9분 시점에 보호 API보다 갱신을 먼저 호출
- 동시에 만료 임박한 Chromium 두 탭에서 웹 락을 사용해 갱신 네트워크 호출 1회, 만료 시각 동기화와 화면·URL 유지
- 갱신 실패는 상태가 아닌 서버 오류 코드로 분류하며, 세션 종료 코드는 즉시 로그아웃하고 일시 오류는 세션 유지 후 10초 뒤 한 번만 재시도
